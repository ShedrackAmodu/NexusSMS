Guidelines for replacements:
- Prefer `user.has_perm('app_label.codename')` where a single permission maps to the capability.
- For capabilities that require multiple permissions, use `user.has_perms(["app.perm1","app.perm2"])`.
- If role membership is required for logic not expressible as permissions (e.g., selecting an institution or primary-role-only flows), keep role checks but add permission fallbacks:
  `if user.has_perm('app.codename') or user.user_roles.filter(role__role_type="teacher").exists():`
- Use `PermissionRequiredMixin` or `@permission_required` for views where appropriate.
